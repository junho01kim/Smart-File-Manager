# Smart File Manager

Windows 터미널에서 실행할 수 있는 간단한 Python 파일 관리 프로그램입니다.  
별도의 외부 라이브러리나 API 키 없이 **Python 기본 라이브러리**만으로 동작합니다.

## 주요 기능

1. **폴더 내 파일 목록 조회**
   - 지정한 폴더 바로 아래에 있는 파일 목록과 크기(bytes)를 출력합니다.
2. **확장자별 파일 분류**
   - 폴더 내 파일들을 확장자 이름(`txt`, `jpg`, `pdf` 등)의 하위 폴더로 정리합니다.
   - 확장자가 없는 파일은 `확장자없음` 폴더로 이동합니다.
   - 동일한 이름의 파일이 이미 있으면 덮어쓰지 않고 건너뜁니다.
3. **중복 파일 검색 (해시 비교)**
   - 하위 폴더까지 포함하여 파일의 SHA-256 해시값을 비교해 내용이 같은 중복 파일을 찾아냅니다.
   - 검색 결과만 출력하며 **실제 파일은 삭제하지 않습니다.**
4. **지정 폴더 ZIP 백업**
   - 지정한 폴더와 하위 폴더 전체를 압축하여 상위 폴더에 백업 ZIP 파일을 생성합니다.
   - 파일명 형식: `폴더명_backup_YYYYMMDD_HHMMSS.zip`

## 파일 구성

```text
smart_file_manager/
├── main.py            # Smart File Manager 메인 실행 파일
├── create_sample.py   # 테스트용 sample 폴더 생성 스크립트 (선택)
└── README.md          # 프로젝트 설명 문서
```

## 실행 환경

- Windows 10 / 11
- Python 3.x (추가 패키지 설치 불필요)

## 실행 방법

1. 터미널(CMD 또는 PowerShell)에서 프로젝트 폴더로 이동합니다.
   ```cmd
   cd C:\smart_file_manager
   ```

2. (선택) 테스트용 `sample` 폴더를 만들고 싶다면 아래 명령어를 먼저 실행합니다.
   ```cmd
   py create_sample.py
   ```

3. 메인 프로그램을 실행합니다.
   ```cmd
   py main.py
   ```
   *(환경에 따라 `python main.py`로 실행할 수도 있습니다.)*

4. 터미널에 표시되는 메뉴 번호(`1`~`4`, 종료 `0`)를 입력하고, 대상 폴더 경로를 입력해 사용합니다.
   - Windows 탐색기에서 폴더를 터미널 창으로 드래그 앤 드롭하면 경로가 편리하게 입력됩니다.

## 주의 사항

- 이 프로그램은 안전을 위해 **파일 삭제 기능을 제공하지 않습니다.**
- ZIP 백업 파일은 기본적으로 대상 폴더의 **상위 폴더**에 저장됩니다.
